# 工作排班系统操作说明文档

本系统旨在为企业/机构提供高效的工作排班管理解决方案，支持移动端操作，涵盖了从排班定义、排班实施到休假申请及审批的全流程闭环管理。

---

## 1. 角色与权限说明

系统根据用户的 `Level` 等级自动切换功能界面：

*   **普通员工 (Level < 30)**：
    *   主要通过“我的排班”查看个人每月的排班计划。
    *   可以提交“请假申请”。
    *   **不可见**：排班矩阵页、排班设置页。
*   **管理人员 (Level ≥ 30)**：
    *   拥有排班管理权，可以为部门内所有人员进行排班。
    *   支持审批员工的请假申请。
    *   可以自定义排班类型（班次）。

---

## 2. 功能模块详述

### 2.1 排班矩阵 (管理员视图)
管理人员通过“排班矩阵”进行全局调度。

*   **周视图导航**：通过顶部的时间切换按钮（◀ / ▶）切换不同周次，系统以周为单位展示所有员工的排班情况。
*   **批量人员选择**：
    *   点击左上角“姓名”表头可全选/取消全选员工。
    *   点击单个员工姓名左侧的选择框可进行单选。
*   **新增排班**：
    1. 点击“+ 新增排班”按钮。
    2. 系统默认开始/结束时间为“今天”。
    3. 如果已提前勾选了人员，系统会自动带入选定的人员名单。
    4. 选择对应的班次类型并填写备注。
*   **冲突检测与覆盖 (核心特色)**：
    *   提交排班时，系统会自动检测所选日期内该人员是否已有排班。
    *   若存在冲突，系统会弹出**【排班冲突确认】**对话框。
    *   该对话框会对比显示 **[原排班类型]** 与 **[新排班类型]**。
    *   用户点击“确认覆盖”后，系统将自动将旧排班更新为新排班。
*   **人员详情预览**：在矩阵中**长按**员工姓名，可弹出该员工的月度排班日历预览。

### 2.2 我的排班 (个人视图)
员工个人的工作计划中心。

*   **月度日历**：以日历形式展示当月所有排班，不同类型的班次（如早班、夜班、休假）通过不同颜色高亮显示。
*   **状态同步**：日历会自动汇总排班表和已审批通过的休假申请，确保信息准确无误。

### 2.3 请假申请与审批
*   **员工申请**：点击“申请休假”，填写起止日期及原因。
*   **审批流**：
    *   申请提交后状态为“待审批”。
    *   管理人员在卡片右上角点击菜单，可执行“通过”或“驳回”操作。
    *   **联动排班**：审批通过后的休假记录会自动反映在排班矩阵和个人日历中，替换原有的普通班次。

### 2.4 班次设置 (配置中心)
由管理员维护本部门的班次规则。

*   **班次属性**：可设置班次名称、类型（常规/夜班/其他）、开始时间、结束时间及持续时长。
*   **快捷生成 (APN班次)**：支持一键生成标准的 A班、P班、N班（早中晚三班），大幅简化初始配置工作。

## 3. 操作小贴士 (Tips)

1.  **颜色标识**：
    *   🟠 **橙色**：早班/A班相关。
    *   🔵 **蓝色**：中班/P班相关。
    *   🟣 **紫色**：晚班/夜班/N班相关。
    *   🟢 **绿色**：休假。
2.  **数据刷新**：如果发现排班信息未及时更新，可以在页面中心向下拖动进行手动刷新。
3.  **批量操作**：管理员通过勾选多名人员，可以实现一人点选、全员同时排班的极速操作。
