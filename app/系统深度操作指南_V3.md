## 1. 登录与权限体系

系统采用严格的角色权限控制，功能界面会根据您的 `Level` 自动调整。

### 1.1 账号注册与组织绑定
1.  **注册**：进入[我的] -> [申请注册]，填写用户名、真实姓名、工号等信息。
2.  **组织加入**：注册后在[所属组织]中搜索您的医院及科室，点击“申请加入”。
3.  **审批**：由对应的护士长或系统管理员在后台审核通过后，您方可查看科室实时数据。

### 1.2 角色定义
*   **管理岗 (Level 30+)**：如护士长、科主任。拥有排班权限、班次定义权、位置编辑权、待办忽略及全量统计权。
*   **临床岗 (Level 20-29)**：如护士、医生。拥有日常业务执行权（交接、出入库、抢救记录、个人排班查看）。
*   **后勤岗 (Level 10-19)**：如保洁、勤务。仅限查看清洁清单及特定保障任务。

## 2. 首页工作台与实时调度

首页是整个系统的“驾驶舱”，集成了实时监控与快捷入口。

### 2.1 状态监控与车辆切换
*   **状态标识**：
    *   **正常 (绿色)**：所有物品足额且在效期内。
    *   **异常 (红色)**：存在过期药品或库存低于预警值。
    *   **抢救中 (闪烁)**：当前车辆正处于启用救援计时状态。
*   **快速切换**：点击车辆名称旁的“▼”图标，可快速切换本科室不同的抢救车/抢救包。

### 2.2 核心指标看板
*   **品规数**：当前车辆存放的物料种类总数。
*   **总价值**：自动根据采购单价计算出的实时资产金额。
*   **待办提醒**：铃铛图标处的数字代表当前登录人需要优先处理的任务（如：待确认的交接单）。

## 3. 核心业务全流程详解

### 3.1 二维码/封条交接 (Handover)
交接是确保物品“状态在位”最频繁的操作。

1.  **发起交接**：点击首页[交接班]按钮。
2.  **选择模式**：
    *   **封条交接**：通过扫描每一层抽屉的二维码或物理封条，确认封条完整，无需点数，快速通过。
    *   **明细核对**：若封条破损或规定的大盘点时间，需拉开抽屉对实物进行逐一点击确认。
3.  **异常处理**：如发现缺项，点击“异常”并备注（如：药瓶破损），系统会立即向管理员推送异常待办。
4.  **签名提交**：系统自动采集当前位置、时间和用户签名，形成闭环。

### 3.2 封存与启封管理 (Sealing)
用于备用车辆的长期管理。

*   **封存操作**：
    1. 点击[封存]，系统生成唯一的电子封存号。
    2. 相关人员确认后，车辆状态变为“已封存”，此时任何出入库操作将被禁止。
*   **启封确认**：
    1. 需要执行[启封]操作，系统会要求用户重新进行一次全量明细核对。
    2. 核对无误后，状态恢复为“正常”。

### 3.3 物品全生命周期管理
*   **智能入库 (Inbound)**：
    *   **GS1解析**：直接扫描药品外盒的复合条码，系统可自动解析出 `批号`、`效期`、`生产日期`。
    *   **库位分配**：指定入库到“1号车-第2层-左侧格位”，实现空间精细化。
*   **出库场景 (Outbound)**：
    *   **抢救出库**：通过抢救记录自动联动，无需手动操作。
    *   **普通领用/报损**：通过[物品出库]模块，选择原因并扫码扣减。

### 3.4 智能辅助抢救 (Emergency)
1.  **启动救援**：点击首页[红色抢救图标]。此时背景变为“作战模式”，计时器开始读秒。
2.  **添加用药**：在救援过程中，可随时点击“+记录”，记录用药时间及名称（支持语音或快捷勾选）。
3.  **结束复核**：抢救完成后，点击“结束抢救”，系统列出所有已用物料。确认后，系统自动完成物料出库并提示补货。
4.  **生成文书**：后台自动生成《抢救用药与项目记录单》，可在线导出打印。

## 4. 智能辅助排班系统 (Scheduling)

### 4.1 矩阵排班 (管理员)
1.  **视图选择**：进入[排班管理]，切换到[排班矩阵]。
2.  **批量勾选**：点击列表左侧选择框勾选待排班人员。
3.  **时间定义**：点击[新增排班]，设置日期范围。
4.  **冲突防御**：
    *   **自动检测**：如果某员工在选定日期已有排班，系统会弹出**【红色冲突对比框】**。
    *   **可视化选择**：对比框会展示“原班次”与“拟改班次”，管理员可一键“确认覆盖”或“保持现状”。

### 4.2 个人排班 (员工)
*   **中心看板**：在[我的排班]日历中，查看每月工作安排。
*   **休假联动**：在[休假申请]提交并由护士长审批后，您的排班日历会自动更新为“休假”状态，并带绿色标识。

### 4.3 班次生成
*   **快捷生成**：管理员在设置中可点击“生成 APN 班次”，一键建立通用的 A班(早)、P班(中)、N班(晚)规则。

## 5. 数据统计与追溯查询

*   **库存快照**：支持随时导出当前科室所有抢救车的库存实盘数据。
*   **动作追踪 (Action Log)**：在物品详情页，可查阅该特定批次药品的所有流通记录（由谁入库、在哪核对过、最终在哪个抢救案例中消耗）。
*   **预警分析**：通过图表分析物品消耗频率，为合理设置“安全库存基数”提供数据支持。

## 6. 系统配置与基础资料维护

### 6.1 位置与设备
*   管理员可根据科室实物，在[位置管理]中自定义抢救车的物理结构（如：5层30格），并对应张贴二维码。

### 6.2 语言与通知
*   **国际化**：在[设置]中切换中/英文视图。
*   **消息路由**：系统会自动根据业务紧急程度，通过邮件或 App 内 Todo 列表进行分级推送。
